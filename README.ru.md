# ZZZ Ultrawide Fix

[English](README.md)

Экспериментальный мод для ZZMI, убирающий боковые чёрные полосы в Zenless Zone Zero при **5120×1440 / 32:9**. Он воздействует на геометрию боковых полос вместо замены общей чёрной текстуры, которую используют подложки меню и затемнения при загрузке.

## Установка

Требуется [XXMI Launcher](https://github.com/SpectrumQT/XXMI-Launcher) с ZZMI и запуск игры в режиме **DirectX 11**.

1. Закройте игру и отключите другие моды для удаления чёрных полос.
2. Скопируйте папку **BlackBarsRemoval** в **ZZMI/Mods**.
3. Запустите игру через XXMI. Для версии Steam выберите **Settings → General → Game Launch → Steam**.

После установки файл должен находиться по пути `ZZMI/Mods/BlackBarsRemoval/BlackBars.ini`.

## Управление

- **F7** — включить или отключить фикс. По умолчанию включён при запуске игры.
- **F10** — перезагрузить конфигурацию ZZMI после редактирования INI.

Для удаления закройте игру и удалите папку **BlackBarsRemoval**.

## Ограничения

Версия 0.1 проверена по записанным кадрам из города, меню Esc и боевого пропуска при 5120×1440. Переходы при загрузке, кат-сцены, другие разрешения и DX12 не проверены.

После обновления игры или смены разрешения правило определения полос может перестать работать. Мод не расширяет интерфейс меню и не меняет угол обзора камеры (FOV). Это неофициальный мод без гарантий совместимости и безопасности аккаунта.
